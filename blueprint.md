# **App Name**: Pre-Marriage Course Enrollment

## Core Features:

- Personal Data Collection: Collects personal information from each participant including full name, date of birth, address, and phone number.
- Relationship Information: Gathers data on the couple's relationship, such as the length of time they have been together, whether they currently live together, and if they have set a wedding date.
- Sacramental History: Checks and records whether each participant has received Catholic sacraments: Baptism, First Communion, and Confirmation. Uses a tool to find the official sacrament dates for canonical reasons.
- Marital Status Verification: Records the marital status of each participant to ensure canonical compliance.
- Form Submission: Allows participants to submit the completed form online.

## Style Guidelines:

- Primary color: Light sky blue (#87CEEB) to represent serenity, faith, and commitment.
- Background color: Very light blue (#F0F8FF), almost white, for a clean and calming feel.
- Accent color: Soft lavender (#E6E6FA) for highlights and interactive elements, evoking trust and gentleness.
- Font pairing: 'Literata' (serif) for headings, 'PT Sans' (sans-serif) for body text.
- Use simple, elegant icons that represent sacraments and milestones in a relationship, such as a cross for baptism, rings for marriage.
- Maintain a clean, linear layout with ample spacing for ease of reading and filling out form fields.
- Use subtle transitions and feedback animations for form submissions to enhance user engagement without distraction.
